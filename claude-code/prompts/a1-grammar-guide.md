# Промпт — гайд по грамматике A1

Запускай на каждую тему A1 по порядку карты: A1-01 → A1-45. Сначала один раз выполни [00-guides-workshop.md](00-guides-workshop.md).

- **Модель:**
  - первый, эталонный гайд — Opus 5.5, effort high;
  - остальные — Sonnet 5.5, effort medium.
- **Одна тема — одна сессия.** Между темами — `/clear`.
- **Что подставить:** `<TOPIC_ID>`, строку про дизайн и строку про видео. Картинки дизайна перетащи в чат или положи в `guides/_refs/<TOPIC_ID>/`.

```
Сделай гайд по грамматике A1 для Alterna. Правила — CLAUDE.md, разделы «Контракт гайда», «Трекинг», «Адаптивность». Основа — guides/_template и kit из public/kit/v1.

ВХОД
- Тема: <TOPIC_ID> (например a1.dative). Всё о теме — из content/maps/alterna-grammar-a1-c1.json: code, title_ru, title_tr, forms, example, prerequisites, note, hours.
- Город: Стамбул (A1). Сцены и примеры — из жизни Стамбула: кафе, транспорт, рынок, знакомство, дом.
- Дизайн: приложенные картинки. Возьми из них: <палитру / шрифты / характер иллюстраций / композицию / тип анимаций>. Воспроизведи стиль кодом (CSS, SVG, GSAP). Сами картинки в гайд не вставляй.
- Видео: <ссылки на YouTube> или «найди сам».

ШАГ 1 — ПЛАН (жди моего «ок»)
- 2–3 умения, которые ученик получит после гайда;
- секции: ключ, заголовок, что показывает анимация;
- видео: название, канал, длительность, таймкоды start–end и почему этот фрагмент;
- упражнения: какие и после каких секций; нестандартное — механика в 3–4 предложениях;
- типичные ошибки русскоязычных, которые разбираешь;
- что берёшь из дизайна.

ШАГ 2 — ГАЙД
Создай папку командой pnpm guide:new <TOPIC_ID>, дальше работай в ней.

Содержание — 5–7 секций:
1. Зачем — живая сцена в Стамбуле, одна фраза-цель.
2. Правило — одна анимированная схема вместо абзаца.
3. Формы — гармония гласных, оглушение, соединительные согласные, если они есть в теме.
4. Ловушки — частые ошибки русскоязычных.
5. В речи — 6–10 примеров и короткий диалог.
6. Шпаргалка — вся тема на одном экране.
7. Итоговый тест.
- Только грамматика из prerequisites и эта тема. Лексика — частотная, уровня A1.
- Объяснения по-русски, на «ты», абзац — не больше 2–3 предложений. Правило показывай движением, а не текстом.
- Каждый турецкий пример — в <a-say> с переводом рядом.
- Турецкий проверь дважды: ı/i, ş, ğ, ç, ö, ü, гармония, аффиксы. Сомневаешься в примере — бери проще.

Видео с YouTube — 1–2 штуки:
- <a-video yt="…" start="…" end="…" title="…" channel="…"> внутри подходящей секции, фрагмент 1–5 минут.
- Если ссылок нет — найди кандидатов поиском. Если доступен YouTube-инструмент с транскриптами — прочитай транскрипт и убедись, что там именно эта тема, уровень A1 и верное объяснение. Предпочитай носителей языка и каналы преподавателей.
- Встраивание должно быть разрешено (pnpm guide:check проверит через oEmbed). Видео не скачивай и не перезаливай.
- Над видео — одна строка «на что обратить внимание», после видео — 1–2 вопроса на понимание.
- Гайд должен быть понятен и без видео: в некоторых странах YouTube не открывается.

Упражнения — в exercises.json папки гайда:
- 3–4 обычных упражнения по ходу гайда, сразу после секции, которую они закрепляют. Типы: gap_fill, multiple_choice, matching, build_sentence, true_false, sort_buckets, error_hunt. Один тип не повторяй два раза подряд.
- 1 нестандартное (type: "custom") — интерактив под механику этой темы в декорациях Стамбула. Примеры:
  · «Маршрут по Стамбулу» — перетаскиваешь места и собираешь «Taksim'e gidiyorum»;
  · «Сортировочный конвейер» — слова едут к -lar или -ler;
  · «Найди ошибку в переписке» — чат в мессенджере;
  · «Кассир на базаре» — слышишь цену и выбираешь сумму.
  Требования: проходится за 1–2 минуты; работает пальцем, мышью и клавиатурой; помещается на 360 px; каждый ответ — AlternaTracker.answer(…), в конце — AlternaTracker.complete(…); правильные ответы описаны в exercises.json.
- Итоговый тест — <a-quiz ref="<TOPIC_ID>.quiz">: 8–10 вопросов разных типов, проходной балл 60%.
- У каждого упражнения: id (<TOPIC_ID>.ex1, .ex2 … / .quiz), topic, skill: "grammar", difficulty 1–3; у каждого вопроса — объяснение для неверного ответа.

Скрытый трекер:
- Подключи kit: /kit/v1/kit.css, /kit/v1/kit.js, /kit/v1/tracker.js, /kit/v1/gsap.min.js. Свой трекинг не пиши — для нестандартного упражнения используй только AlternaTracker.
- Каждая секция: <section data-section="ключ" data-words="N">. Ключи латиницей и навсегда, N — реальное число слов русского текста секции.
- Ученик не видит никаких счётчиков и процентов. Статистика видна только в ?debug=1, а позже — в дашборде платформы.

Дизайн и устройства:
- Mobile-first: 360 → 768 → 1280 → 1920 px, без горизонтального скролла; текст не шире 75 знаков; кнопки ≥ 44 px.
- GSAP + ScrollTrigger; ScrollTrigger.refresh() при повороте экрана; при prefers-reduced-motion — итоговое состояние без анимации.
- JS + CSS ≤ 400 КБ без медиа; свои картинки — SVG или WebP ≤ 150 КБ.

ШАГ 3 — ПРОВЕРКА
1. pnpm guide:check <TOPIC_ID> — исправь всё, что упало.
2. Открой /player?topic=<TOPIC_ID>&debug=1 и пройди гайд: % прочитанного дошёл до 100, каждое упражнение и видео дают события, пришёл guide_complete.
3. Отчёт мне:
   - секции и число слов;
   - все турецкие примеры с переводом — отдам на проверку носителю;
   - видео с таймкодами;
   - упражнения с правильными ответами;
   - что взял из дизайна.
```

## После гайда

- Проверь гайд на телефоне: открой `pnpm guides:dev` по IP компьютера в той же Wi-Fi-сети.
- Турецкие примеры из отчёта отдай носителю языка.
- Когда всё ок — смени статус темы на «готов» (`status: "ready"` в `guide.json`) и закоммить.
