# Alterna — план на 10 дней для Claude Code

Положи `CLAUDE.md` и этот файл в корень нового репозитория `alterna`. Каждый день — 1–3 сессии Claude Code.

## Как работать

| Шаг | Модель | Effort | Что делаешь |
|---|---|---|---|
| План дня | Opus 5.5 | high | Plan mode (Shift+Tab), вставь промпт дня, прочитай план, поправь, утверди |
| Код | Sonnet 5.5 | medium | Переключи модель и effort, выполняй план по задачам |
| Сложная логика | Sonnet 5.5 | high | Трекер, построитель плана, движок упражнений |
| Деньги и безопасность | Opus 5.5 | high | Схема БД, RLS, роли, Paddle, доступ к гайдам |
| Ревью вечером | Opus 5.5 | high | `/code-review` по изменениям дня |
| Аудит перед запуском | Opus 5.5 | xhigh или max | `/security-review`, сложные баги |
| Гайды по шаблону | Sonnet 5.5 | medium | Отдельная сессия, один промпт на тему |
| Мелкие правки | Sonnet 5.5 | low | Тексты, стили, переименования |

Правила работы:

- Одна задача — одна сессия. Между задачами — `/clear`, чтобы контекст не засорялся.
- После каждой фичи: тесты → проверка на телефоне (360 px), iPad (820 px) и широком экране (1920 px) → коммит → превью на Vercel.
- Если Claude предлагает «заодно» сделать что-то вне промпта — отказывайся. Записывай идею в `docs/later.md`.

## День 1 — фундамент и лендинг

**Модели:** Opus · high — план, Sonnet · medium — код.

```

2. Триггер на регистрацию: создать profile, trial_ends_at = now() + interval '7 days'.
3. Custom Access Token Hook: claim app_role в JWT. Права выдай по документации Supabase.
4. Вход: email-код (OTP) и Google. Клиенты через @supabase/ssr; ключи NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY и SUPABASE_SECRET_KEY; на сервере — getClaims().
5. proxy.ts: обновление сессии; /admin только admin|superadmin; /superadmin только superadmin; (app)/* только для вошедших.
6. Каркас по docs/design/plan.png: сайдбар (План, Дашборд, Повторение слов, Грамматика, Лексика, Ресурсы, Игры, Настройки), профиль внизу. Сразу все 5 раскладок из раздела «Адаптивность» CLAUDE.md: телефон с нижней панелью, планшет с панелью иконок, ноутбук с сайдбаром, большой экран с правой колонкой, ультраширокий по центру. viewport-fit=cover, safe-area, dvh, брейкпоинты 3xl/4xl в @theme, плашка для старых браузеров.
6a. playwright.config.ts с 9 профилями устройств из CLAUDE.md и тест «нет горизонтального скролла» на главной и каркасе.
7. Лендинг (marketing): главная, тарифы, оферта, политика конфиденциальности, возвраты — черновые тексты-заглушки.
8. Sentry и PostHog (без автозахвата). vercel.json: регион функций fra1.
Ничего сверх списка. В конце — как проверить каждый пункт.
```

**Готово, когда:** лендинг и вход работают на твоём домене, `/admin` для обычного пользователя закрыт. После этого обнови в Paddle адрес сайта для проверки.

```

```

**Готово, когда:** тестовый гайд открывается только после входа, без входа — 403. С этого дня запускай конвейер гайдов — см. ниже.


## Конвейер гайдов (со дня 3, отдельная сессия)

Мастерская гайдов уже сделана в репозитории alterna; стартовый промпт для чатов с гайдами — `docs/guides/START-PROMPT.md` там же. В день 3 остаётся только маршрут `/g/…` и publish.

Короткая версия:

Первый, эталонный гайд делай на **Opus · high**, остальные — на **Sonnet · medium**.

```
Сделай гайд для темы <topic-id> из content/maps. Основа — guides/_template, контракт — раздел «Контракт гайда» в CLAUDE.md.
- Папка guides/<город>/<topic-id>/: index.html, guide.json, media/.
- Уникальный дизайн и GSAP-анимации под тему: показывай правило анимацией, а не абзацем текста.
- Объяснения по-русски, примеры по-турецки, каждый турецкий пример — в <a-say>.
- 4–7 секций со стабильными ключами + тест; упражнения в exercises.json папки гайда.
- Mobile-first: от 360 px до 1920 px без горизонтального скролла, на широком экране текст не шире 75 знаков; JS + CSS ≤ 400 КБ.
После — pnpm content:check <topic-id> и исправь всё, что упало.
```

Порядок — по маршруту: Стамбул (73) → Измир (60) → Анталья (61) → Анкара (49) → Самсун (67).

Темп 10–15 гайдов в день с твоей проверкой → все 310 примерно за 3–4 недели.
